## 🚀 API USAGE

### Create Dashboard
```bash
POST /api/bi/dashboards
{ "name": "Executive Dashboard", "description": "..." }
```

### Get Analytics
```bash
GET /api/bi/analytics?metric=revenue&days=30
```

### Generate Report
```bash
POST /api/bi/reports
{ "type": "sales", "format": "pdf", "dateRange": {...} }
```

### Export Data
```bash
POST /api/bi/export
{ "type": "report", "format": "excel" }
```
